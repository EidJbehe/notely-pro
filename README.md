# 📝 Notely Pro

A full-stack notes application built with a modern tech stack.
Create, edit, delete, search, and organize your notes with a clean and professional UI.

---

## 🚀 Live Demo

👉 Frontend: https://notely-pro-frontend.vercel.app/
👉 Backend API: https://notely-pro-96669928844.us-central1.run.app

---

## ✨ Features

* ➕ Create notes
* 📖 View all notes
* ✏️ Edit notes
* ❌ Delete notes
* 🔍 Search notes
* ⬇️ Sort notes (Newest / Oldest)
* 🔔 Toast notifications
* 🎨 Clean and responsive UI

---

## 🛠️ Tech Stack

### Frontend

* React + TypeScript
* Vite
* Tailwind CSS
* Axios
* React Hot Toast

### Backend

* Node.js
* Express.js
* REST API
* Cloud Run

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

```bash
git clone https://github.com/EidJbehe/notely-pro.git
cd notely-pro
```

---

### 2️⃣ Run Backend

```bash
cd notely-pro-api
npm install
npm run dev
```

---

### 3️⃣ Run Frontend

```bash
cd ../notely-pro-frontend
npm install
npm run dev
```
